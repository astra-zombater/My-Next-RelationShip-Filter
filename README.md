# My Next Relationship Filter 💖

An interactive, web-based augmented reality (AR) style filter application built with pure HTML5 Canvas, JavaScript, Web Speech API, and MediaStream recording capabilities.

A webcam-composite AR filter that uses the Web Speech API to tell you exactly who you're matching with next. Unfiltered, and probably too honest.

## ✨ Features

* **Live Webcam Feed**: Mirror-mode user stream integrated directly beneath HTML5 Canvas overlays.
* **Voice Control Integration**: Trigger the filter sequence hands-free using Web Speech API keywords (e.g., *"Start"*, *"Go"*, *"Run"*).
* **Dynamic Canvas Animation**: Smooth path drawing with random slot-machine style trait selector.
* **Integrated Screen Recorder**: Canvas + Video stream composite recorder saving `.mp4` or `.webm` files directly to disk.
* **Auto Screenshot**: Exports PNG snapshots automatically upon filter completion.
